About

ClassHub

A social learning platform for tuition classes in Sri Lanka

One place for teachers, institutes and students: run the tuition business, reach new students, share knowledge and sell learning content. Built as a Laravel API with a separate React frontend.

Platform features

  • Tuition class managementFull control of classes for teachers and institutes: class setup, schedules, students, enrollment and fees.
  • Marketing campaignsPromote classes to students and parents through SMS, WhatsApp and email campaigns.
  • Social wallA shared feed where teachers, institutes and students post ideas, events and educational content.
  • LibraryTeachers and institutes publish and share educational material with their students and the wider community.
  • MarketplaceTeachers and institutes sell their courses and publications to learners.

Engineering

  • Clean, layered architecture: controllers, services and repositories keep business rules independent of the framework and the database
  • SOLID principles: single-purpose services, and dependency inversion through repository interfaces bound in service providers
  • Design patterns: Repository, Service layer, Strategy/Manager (swappable SMS gateway drivers), Facade, Result object, Form Request validation and a middleware pipeline
  • Production habits: idempotent requests, rate limiting, request tracing, structured error logging, queued email jobs and token authentication with refresh

Built so far

  • Multi-step onboarding for teachers and institutes: classes, medium, class size, fees, location, an advertisement image with a built-in editor, and a payment step
  • Student, teacher and institute roles with route guards, a role switch and a teacher dashboard
  • Dockerised React frontend served by nginx, with mocked APIs for working without the backend

BillBook

Point-of-sale and inventory system for shops

A Windows desktop app for running a shop counter: billing, stock, customers, suppliers and reports in one place. Around 37,000 lines of Java, shipped with an installer and in-app updates.

Features

  • Billing and counterFast keyboard billing, multiple tills, change handling, discounts, returns and quotations, with counter close and a day summary.
  • InventoryBatch-wise stock, stock counts and sheets, stock history, low-stock alerts, and barcode labels (Code 128 and EAN-13) with a label designer.
  • Customers and suppliersCustomer credit and previous balances, on-account payments, purchasing, supplier discounts and supplier balances.
  • Finance and reportsExpenses, a cash book, profit, and reports grouped by sales, profit, stock, customers, suppliers and finance, with charts.
  • Users and securityRole-based access down to individual actions, admin approval with a password, hashed passwords, an activity log and backups.
  • Works offlineKeeps billing when the server is unreachable and uploads the bills when the connection returns. Runs on a local database or a shared one.
  • HardwareReceipt printer with a logo, cash drawer, customer display and an on-screen keyboard.
  • Sinhala and TamilItem names in English, Sinhala and Tamil, with built-in transliteration for typing.

Engineering

  • Layered structure: models, repositories, screens, reports, printing, notifications and updates each live in their own package
  • SOLID principles: open for extension without touching the screens (add a notification source or a report by adding one entry), small focused interfaces, and one repository per business area
  • Design patterns: Repository, Strategy (every report is a pluggable function in a catalog), store-and-forward queue for offline bills, singleton session, and immutable value objects
  • Reliability habits: every change is written to an audit log inside the same database transaction, slow work runs off the screen thread, and updates and the installer ship through GitHub releases
